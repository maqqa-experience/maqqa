# LeetCodeDataset slim corpus

Imported from [newfacade/LeetCodeDataset](https://github.com/newfacade/LeetCodeDataset) (MIT).

Regenerate:

```bash
python3 scripts/import_leetcode.py --clone
```

Files:

- `v0.3.1-test.jsonl.gz` — 228 problems (temporal test split)
- `v0.3.1-train.jsonl.gz` — 2641 problems
- `manifest.json` — counts + field list
- `LICENSE` — upstream MIT license

Reference solutions are stripped; `vibe_bench` materializes stub + unittest per problem at runtime.
